Privacy Policy

GSC for Claude · Last updated September 2026

GSC for Claude ("the App") is operated by Elite Information Tech ("we", "us"). This policy explains what data the App accesses via Google APIs and how it is used, in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

What data we access

When a Google account owner grants the App access, it may read:

  • Google Search Console data (indexed pages, page-indexing status, crawl data) for properties the account owns or manages.
  • Google Analytics reporting data for properties the account has access to.
  • Google Ads keyword search-volume and account data (via the Google Ads API), for accounts the connecting user manages.

What we do with it

Data read via these APIs is used only to generate the specific report or result the connecting user requested (e.g. a Search Console indexing report, a keyword search-volume lookup). We do not sell this data, share it with third parties, or use it to serve advertising. Access tokens are stored only to keep a connected account signed in for future requests initiated by that same user, and can be revoked at any time from the account's own Google Account permissions page.

Data retention

Report data generated on a user's behalf is retained only as long as needed to deliver that report. OAuth tokens are retained only until the connected account revokes access or the connection is removed by the user.

Contact

Questions about this policy or a request to remove data can be sent to team@eliteinformationtech.com.
